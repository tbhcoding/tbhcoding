## Machine Learning & Computer Vision

| Project | Description |
|:--|:--|
| **[XpHectra](https://github.com/tbhcoding/XPHECTRA)**<br><sub>Multispectral pH mapping · thesis</sub> | Pixel-wise pH mapping of pork from six-band multispectral images. A U-Net-style CNN reconstructs the full pH map from four probe readings, trained on a physics simulator with literature-sourced parameters. **MAE 0.094 pH, R² 0.85** on 500 held-out synthetic samples, ahead of linear and PLS baselines across the full sensitivity sweep.<br><sub>My role: forward model and data generator, parameter sourcing, reproducibility and metric audits.</sub><br>`PyTorch` `NumPy` `SciPy` `scikit-learn` `OpenCV` `Gradio` |
| **[Intelligent Energy Forecasting](https://github.com/tbhcoding/Intelligent-Energy-Forecasting)**<br><sub>Time-series forecasting</sub> | Stacked RNN vs. LSTM for next-day household electricity forecasting on the UCI Household Power dataset, with outlier handling, resampling and cyclical time features. The LSTM cut MSE by 12.7%, a gap that wasn't statistically significant. [Paper](https://github.com/tbhcoding/Intelligent-Energy-Forecasting/blob/main/paper.pdf)<br>`TensorFlow` `pandas` `scikit-learn` `SciPy` |
| **[Sleep Disorder Prediction](https://github.com/tbhcoding/SleepPrediction-ML)**<br><sub>Classification</sub> | Predicts insomnia, sleep apnea or no disorder from health and lifestyle data, comparing XGBoost, Gradient Boosting, KNN and Logistic Regression with SMOTE balancing. The top models reach about 90–92% accuracy, served through an interactive prediction widget.<br>`scikit-learn` `XGBoost` `imbalanced-learn` `pandas` `Plotly` |
